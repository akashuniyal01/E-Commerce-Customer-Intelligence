# E-Commerce-Customer-Intelligence
# Project Overview
The E-Commerce Customer Intelligence project focuses on analyzing customer purchasing behavior and segmenting customers into meaningful groups using machine learning. The project uses Python, MySQL, Pandas, Scikit-learn, and K-Means clustering to identify different types of customers based on their purchasing patterns.

The main objective is to help businesses understand their customers, identify valuable customer groups, and make data-driven marketing decisions.


# Objectives
- Create and manage a MySQL database for e-commerce data.
- Perform ETL (Extract, Transform, Load) operations to prepare the data for analysis.
- Perform feature engineering to generate meaningful customer-level features.
- Apply K-Means clustering to segment customers based on purchasing behavior.
- Evaluate different values of K to select a suitable number of clusters.
- Store customer segmentation predictions in MySQL.
- Save the trained machine learning model and scaler for future use.
- Predict customer segments for new customers using the saved model.
